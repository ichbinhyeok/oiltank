# Source and model notes

- Decision question: does the current Oil Tank Route product surface have evidence-backed leverage to reach 100 U.S. organic clicks per day?
- Audience: product stakeholder / owner-operator.
- Target definition: 3,000 organic clicks per 30-day month.
- Demand inputs: the reviewed Google Ads Keyword Planner exports and the two previously documented cluster models. Utility base demand is 27,100 searches/month; commercial base demand is 23,122; combined raw base is 50,222 before semantic close-variant overlap.
- Search Console baseline: June 11 through July 8, 2026; 208 impressions and 0 clicks across nine legacy routes. It predates the new product URLs, so it is evidence of the domain's starting authority, not a post-launch evaluation of those URLs.
- Current implementation inventory: 20 indexable routes, including nine core product routes. The delivery-check URL has no measured Keyword Planner demand in the reviewed files, so its incremental acquisition demand is counted as zero until query data appears.
- CTR benchmark: May 2026 U.S. desktop position estimates cited in the existing traffic assessment: P1 14.61%, P2 9.24%, P3 3.66%, P4 1.51%, P5 1.17%, P10 0.53%. Actual mobile and SERP-feature CTR may be lower.
- Semantic overlap is not measured by Keyword Planner. Exact duplicate keywords between the 50-row utility export and 103-row expanded-commercial export are zero, but close variants remain. The report therefore shows 20%, 35%, and 50% overlap sensitivity rather than presenting one adjustment as fact.
- Formula: adjusted pool = 50,222 x (1 - overlap); clicks/day = adjusted pool x position CTR / 30.
- Chart contract: section = ranking requirement; question = how average rank and semantic overlap change attainable daily clicks; family = comparison; type = vertical bar; fields = scenario, clicks_per_day, monthly_search_pool, ctr; single-root blue palette; full-width HTML report.
- Required executive roles map: Title; Executive Summary; findings with visual evidence; recommended next steps; further questions; caveats and assumptions.
- Omitted metric: accepted-lead conversion. No post-pivot traffic-to-approved-lead dataset exists, so the report does not infer whether 100 clicks/day produces 40 approved leads/month.
