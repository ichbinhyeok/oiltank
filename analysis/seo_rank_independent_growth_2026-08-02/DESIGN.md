# Report design contract

- Audience: Oil Tank Route founder and product stakeholders.
- Purpose: decide whether the 100 organic clicks/day plan can work without assuming an average position of 2.
- Hierarchy: answer-first executive summary, one decisive comparison chart, exact decision thresholds, then evidence gaps and next actions.
- Palette: ivory background, ink navy text, safety orange only for the 100-click target or decision emphasis. Charts use a single blue root plus neutral reference styling.
- Typography: system sans for prose and system monospace for quantitative values in the portable reader.
- Accessibility: no meaning conveyed by color alone; every chart value is also available in the semantic data table; concise headings and high-contrast text.
